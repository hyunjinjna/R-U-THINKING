# R U Thinking? 웹사이트

학생용 / 선생님용 허브 사이트. 구글 스프레드시트를 데이터 원본으로 사용하므로, 시트만 수정하면 웹사이트 내용이 바뀝니다.

- **학생용**: `/` — 대분류 → 반 선택 → 줌 / 클래스카드 / 숙제 / 개념설명 / 필기인증 / 포인트 / 질문하기
- **선생님용**: `/teacher` — 비밀번호 → 반 관리 / 주간 리포트 / 질문 답변 도우미 / 코치 자료

---

## 이번 업데이트 내용

1. **회차 기준으로 전면 수정** — 레벨 하나(예: Easy Link 5) 안에서 1~12회차로 진행. 주 2회면 한 주에 2회차, 주 3회면 3회차가 나감
2. **비밀번호 매번 입력** — 새로고침하면 다시 물어봄
3. **개념 설명하기 모드** — 학생이 음성으로 개념 설명 → AI가 힌트 주며 확인
4. **커리큘럼 마스터 열 추가** — 개념설명숙제 / 설명언어
5. **숙제 미제출 자동 SMS** — 대시보드에 미제출 기록되면 학생별 가능시간에 자동 발송
6. **코치 반 관리에 "오늘 수업" 우선 표시**
7. **질문 답변 도우미** — 학부모 문의에 AI가 FAQ 기준으로 답변 초안 작성
8. 코치 반 상세에 줌 · 영상 · 대시보드 · 클래스카드 한 화면에

## 스프레드시트 구성 (총 5개)

### 1. 운영 스프레드시트

| 반이름 | 대분류 | 수업요일 | 수업시간 | 시작일 | 총회차 | 종료여부 | 레벨 | 줌링크 | 대시보드링크 | 대시보드CSV | 필기인증링크 | 휴강기록 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|

| 열 | 형식 | 설명 |
|---|---|---|
| 대분류 | `파닉스` / `리딩` | 학생 화면 첫 단계 구분 |
| 수업요일 | `월수금` `화목` | 붙여서. 회차 계산에 사용 |
| 시작일 | `2026-09-15` | 회차 계산 기준 |
| 총회차 | `12` | 넘으면 "커리큘럼 완료" |
| 레벨 | `Easy Link 5` | 커리큘럼 마스터와 **정확히 일치** |
| 대시보드링크 | 편집 링크 | 코치가 수업 중 여는 주소 |
| 대시보드CSV | 게시 CSV 링크 | AI가 리포트/SMS에서 읽는 주소 |
| 휴강기록 | `2026-03-05, 2026-03-12` | 이만큼 회차가 밀림 |

### 2. 커리큘럼 마스터

| 레벨 | 회차 | 진도 | 클래스카드URL | 숙제범위 | 영상URL | 개념설명숙제 | 설명언어 |
|---|---|---|---|---|---|---|---|
| Easy Link 5 | 1회차 | Unit 1 | https://classcard... | Workbook p.4-6 | https://youtu.be/... | Main idea 찾는 법 설명하기 | 영어 |
| Easy Link 5 | 2회차 | Unit 2 | https://classcard... | Workbook p.7-9 | https://youtu.be/... | Supporting detail 설명하기 | 영어 |

**한 레벨 안에서 1회차부터 총회차까지 전부 채워주세요.** 레벨마다 탭을 나누지 말고 한 시트에 `레벨` 열로 구분합니다.

`회차` 열은 `1회차` `1주차` `1` 어떤 표기든 숫자만 맞으면 인식됩니다.

`설명언어`는 `한국어` 또는 `영어`. 영어면 학생이 영어로 설명하고 AI도 영어로 대화합니다.

### 3. 학생 명단

| 이름 | 반이름 | 전화번호 | 월가능시간 | 화가능시간 | 수가능시간 | 목가능시간 | 금가능시간 |
|---|---|---|---|---|---|---|---|
| 김민준 | 파닉스1-A반 | 010-1234-5678 | 18:00 | | 18:00 | | 18:00 |

`반이름`은 운영 스프레드시트와 **정확히 일치**해야 합니다.
전화번호와 가능시간은 숙제 미제출 자동 문자 발송에 사용됩니다. 비워두면 문자가 안 갑니다.

### 4. 코치 자료 시트

| 자료이름 | 링크 | 설명 | 이모지 |
|---|---|---|---|

### 5. 자주 묻는 질문 시트 (신규)

| 질문유형 | 예시질문 | 표준답변가이드 |
|---|---|---|
| 결석 | 오늘 아이가 아파서 못 가요 | 보강 안내. 당일 결석은 보강이 어려울 수 있음을 정중히 안내하고 수업 영상 다시 보기 안내 |
| 결제 | 환불 가능한가요 | 원장님 확인 후 안내드리겠다고 답변. 임의로 확정하지 말 것 |

질문 답변 도우미가 이 기준을 참고해서 답변 초안을 만듭니다.

### 6. 일일 대시보드 (반마다 별도, 한 탭에 계속 쌓기)

| 날짜 | 회차 | 반이름 | 이름 | 출석 | 단어점수 | 재시결과 | 매일단어 | 연속일수 | 코드1 | 코드2 | 수업태도 | 필기인증 | 특이사항 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|

**필수 열 두 개만 지키면 됩니다:**
- `날짜` — `2026-09-15` 형식
- `이름` (또는 `학생이름`) — 학생 명단과 동일하게

나머지 열은 자유롭게 바꾸셔도 AI가 다 읽어서 리포트에 반영합니다.

**자동 문자를 쓰려면** `숙제` 열에 미제출인 경우 `X` 또는 `미제출`로 기록해주세요.

**보기 편하게 하려면** `데이터` → `필터 보기 만들기`로 오늘 날짜만 걸러서 보세요.

## 자동 문자 발송 동작 방식

```
15분마다 자동 실행 (오전 9시 ~ 오후 10시)
    ↓
각 반의 대시보드에서 "오늘 날짜 + 숙제 미제출" 학생 찾기
    ↓
학생 명단에서 그 학생의 오늘 요일 가능시간 확인
    ↓
지금이 그 시간대면 문자 1회 발송
    ↓
"[R U Thinking?] OO 학생, 오늘 숙제가 아직 제출되지 않았어요.
 지금 바로 클래스카드 완료하고 숙제 제출해주세요!"
```

## 문제 해결

| 증상 | 원인 |
|---|---|
| "시트를 불러올 수 없습니다" | 웹에 게시 안 됨. CSV 형식 확인 |
| 진도/클래스카드가 안 나옴 | 운영 시트 `레벨`과 커리큘럼 마스터 `레벨` 불일치 (띄어쓰기 확인) |
| 회차가 실제와 다름 | `시작일` · `수업요일` · `휴강기록` 확인 |
| 리포트에 "기록이 없습니다" | 대시보드에 이번 주 해당 학생 행이 없거나 `대시보드CSV`가 비어있음 |
| `invalid x-api-key` | API 키가 레거시 키이거나 만료됨. 새로 발급받아 교체 |
| 문자가 안 감 | SMS 환경변수 미설정, 전화번호/가능시간 미입력, 발신번호 미등록 |

# 이번 업데이트 추가 내용

## 새로 생긴 페이지

| 주소 | 용도 |
|---|---|
| `/register` | **등록 현황판** (신규 학부모용, 학생 사이트와 완전 분리) |
| `/teacher/upload` | **성적 업로드** (클래스카드 엑셀 자동 분석) |

## 1. 시간대(KST) 버그 수정

서버는 UTC로 도는데 학원은 한국 시간이라, 한국시간 자정~오전9시 사이에 "오늘 개강한 반"이 개강 전으로 잘못 뜨던 문제를 고쳤습니다. 이제 회차 계산·SMS 발송 시간 판단 모두 한국 시간 기준입니다.

## 2. 휴강기록 띄어쓰기 문제 해결

`2026-09-09, 2026-09-11`처럼 쉼표 뒤에 공백이 있어도 정상 인식합니다. 세미콜론(`;`)이나 줄바꿈으로 구분해도 됩니다.

## 3. 숙제 일차별 공개

커리큘럼 마스터의 `숙제범위`에 `[D+1]`, `[D+2]` 태그를 붙이면 그 날짜가 되어야 학생 화면에 열립니다.

```
1. 단어학습 [D+1]
2. 워크북 [D+2]
3. 말하기 [D+2]
4. 예습 (태그 없으면 항상 공개)
```

수업 당일(D+0)에는 태그 없는 항목만, 다음날(D+1)에는 단어학습까지, 그 다음날(D+2)에는 전부 열립니다. 아직 안 열린 항목은 학생 화면에 자물쇠로 표시됩니다.

**주의**: 웹사이트는 학생이 직접 들어와야 보이므로, SMS 발송 기능과 함께 써야 효과가 있습니다.

## 4. 숙제 팝업

학생 화면에서 "이번 회차 숙제"를 누르면 팝업이 뜨면서 큰 글씨로 보입니다. 줄바꿈이 그대로 살아나고, 닫기 버튼과 배경 클릭으로 닫힙니다.

## 5. 개념 설명하기 — 마이크 연속 인식

말하다 잠깐 멈춰도 마이크가 꺼지지 않습니다. 학생이 마이크 버튼을 다시 눌러야 멈춥니다. 말하는 중에도 화면에 실시간으로 글자가 표시됩니다.

## 6. 시크릿 코드

커리큘럼 마스터에 **`시크릿코드`** 열을 추가하면, 코치 반 상세 화면에 이번 회차 코드가 노란 배지로 표시됩니다. 코드는 1개입니다.

## 7. 로고 · 뒤로가기 버튼

학생 사이트 첫 화면에 로고가 들어갔고, 뒤로가기가 회색 글씨에서 눈에 띄는 버튼 형태로 바뀌었습니다.

**흐름**: 대분류 → 레벨 선택 → 그 레벨의 전체 시간표 (+ "지금 가능한 시간대만 보기" 체크박스)

## 새 시트 1 — 시간표 슬롯

구글폼을 만들어서 응답이 이 시트에 쌓이게 하세요.

| 레벨 | 수업요일 | 수업시간 | 이름 | 연락처 | 처리여부 |
|---|---|---|---|---|---|

- 대기 인원은 **자동으로 카운트**되어 화면에 "대기 3/6"으로 표시됩니다

# 성적 업로드 (`/teacher/upload`)

## 사용법

1. 클래스카드 → 해당 반 → 리포트 → 세트 학습현황 → 엑셀 저장 (상세기록 포함)
2. 코치 사이트 → 성적 업로드 → 파일 선택
3. 자동으로 학생 매칭 + 분석 결과 표시

**엑셀은 반 단위로 받습니다.** 학생별로 따로 받을 필요 없습니다.

## 자동으로 해주는 것

- **학생 자동 매칭**: 엑셀의 `학생명`을 학생 명단 시트의 `이름`과 대조. 이름이 없거나 동명이인이면 그 줄만 "확인 필요"로 표시되고 나머지는 자동 처리됩니다
- **과목별 지표 자동 선택**: 세트 제목을 보고 그 과목에서 중요한 항목만 분석합니다
  - 단어/보카 → 암기, 리콜, 매칭 최고, 테스트 최고
  - 문법 → 맞은문항수, 틀린문항수, 테스트 최고
  - 리딩(Easy Link, Subject Link) → 테스트 최고, 맞은문항수, 틀린문항수
  - 파닉스 → 암기, 리콜, 테스트 최고
  - 스피킹 → 스피킹(%), AI 평가 점수
- **목표 대비 판정**: 업로드 화면에 `암기 300, 리콜 100`처럼 적어두면 미달/달성/초과 달성을 자동 판단합니다
- **반 내 순위**: "반 최고점", "반 상위 30%", "반 하위권(평균 얼마)" 형태로 자동 계산
- **제출일**: 마감일을 입력하면 제출일과 함께 표시됩니다

분석 결과를 복사해서 일일 대시보드에 붙여넣으면 주간 리포트 생성 시 자동 반영됩니다.

# 레벨테스트 시스템 (`/leveltest`)

네 번째 독립 페이지. 학생 사이트, 코치 사이트, 등록 현황판과 완전히 분리되어 있습니다.

## 흐름

```
진입 분기: A(종합) / B(특정 교재)
    ↓
파닉스 게이트 (4~5문제, 절반 이상 맞으면 통과)
    ↓ 통과 못하면 → 바로 전화번호 입력 (나머지 영역 생략)
리딩 (렉사일 기준 적응형, 최대 8문제)
    ↓
단어 (CEFR 기준 적응형)
    ↓
문법 (12단계 적응형)
    ↓
전화번호 입력 → 자동채점 → AI 리포트 생성 → 화면 표시
    ↓
Julia가 리포트 복사해서 카톡으로 발송 (수동)
```

**B(특정 교재) 선택 시**: 해당 영역만 정식 진행, 관련 영역은 생략(현재 구현은 리딩→단어까지 자동 진행 후 종료. 필요시 조정 가능).

## 적응형 로직 — 신뢰구간 좁히기

`lib/adaptive.js`에 구현. "이 학생 실력은 A~B 사이"로 시작해서, 맞으면 하한을 올리고 틀리면 상한을 내리며 범위를 좁힙니다. 범위가 좁혀지거나 최대 8문제에 도달하면 그 시점 값으로 확정합니다. 시뮬레이션 테스트 결과 3~6문제 안에 정확히 수렴합니다.

## 문제 은행 — 새 시트 4개 필요

기존에 만들어드린 `레벨테스트_문제은행.xlsx`를 구글 드라이브에 업로드해서 구글시트로 변환하고, **탭별로 각각 "웹에 게시"**해서 CSV 링크 4개를 받으세요.

| 환경변수 | 시트 |
|---|---|
| `SHEET_PHONICS_Q_URL` | 파닉스 탭 |
| `SHEET_READING_Q_URL` | 리딩 탭 |
| `SHEET_VOCA_Q_URL` | 단어 탭 |
| `SHEET_GRAMMAR_Q_URL` | 문법 탭 |

**시트를 안 채워도 지금 당장 테스트 가능합니다** — 각 영역에 예시 문제 5~6개씩 데모 데이터로 이미 들어있어서, 환경변수 없이도 전체 흐름이 작동합니다.

## 구멍 태그 수집 방식

- **리딩**: 문제유형 자체가 구멍 (오답 시 그 문제의 유형이 곧 구멍)
- **단어/문법**: 오답 보기마다 별도 태그, 어느 보기를 골랐는지에 따라 다른 구멍이 기록됨

## 결과 → 실제 반 매핑

`lib/adaptive.js`의 `lexileToLevel`, `VOCA_LEVEL_MAP`, `grammarStageToLevel` 함수가 처리합니다. 렉사일/CEFR/단계 값을 실제 운영 반 이름으로 변환해서 리포트에 "추천 반"으로 표시합니다. **개설 여부와 무관하게 추천**되며, 리포트의 "바로 등록하기" 버튼을 누르면 `/register`(등록 현황판)로 이동해서 실제 등록 가능 여부를 확인합니다.

## AI 리포트

`/api/leveltest-report`가 처리합니다. 직설적/단정적 톤, 구체적 통계(%, 인원수) 지어내기 금지, 이 학생의 실제 오답 패턴에만 근거해서 작성하도록 프롬프트에 명시되어 있습니다.

## 아직 남은 작업

- 각 영역 실제 문항 대량 작성 (지금은 영역당 5~6개 샘플만)
- B(특정교재) 진입 시 정확히 어느 영역까지 볼지 세부 조정
- 카카오톡 발송은 여전히 수동 (Julia가 리포트 복사해서 발송)

## 레벨테스트 변경사항

**1. 인트로 문구 변경**
"아이의 정확한 영어 실력, 대치동 200명을 가르친 노하우로 진단해드려요."
(기존 "시험이 끝나면 전화번호를..." 안내 문구 삭제)

**2. B 선택지 변경**
"어떤 교재를 들을지 이미 정하고 왔어요"

**3. B 진입 흐름 신설**
```
B 선택 → 대분류(리딩/그래머/보캡) → 교재 목록 → 해당 영역만 시험
         하단에 "어떤 교재인지 잘 모르겠다면 → 종합 레벨테스트" 링크
```
B로 진입하면 **파닉스 게이트는 완전히 생략**됩니다.

**4. 전화번호 형식 검증**
010으로 시작하는 11자리 숫자가 아니면 "전화번호를 정확히 입력해주세요" 메시지가 뜨고 진행이 막힙니다. 화면과 서버 양쪽에서 검증합니다.

**5. 제출 후 리포트 비노출**
전화번호 제출하면 학생 화면에는 "제출이 완료되었어요" 안내만 나오고, 리포트 내용은 보이지 않습니다.

**6. 파닉스 레벨 판별 구현**
게이트 통과 시 답변 패턴을 분석해 EFL Phonics 1~5권 중 어디인지 자동 추정합니다. (기존에는 무조건 1로 고정되어 있던 버그)

**7. 파닉스 게이트 통과 시 리포트에서 제외**
통과하면 파닉스 섹션이 리포트에 아예 나오지 않고, 미통과일 때만 "파닉스 기초반부터 시작" 섹션이 표시됩니다.

**8. 리포트 표현 다양화**
"대치동에서 200명 넘게 가르치며" 같은 문장 틀과 "자주/많이/여러 번/종종" 같은 빈도 표현을 매번 다르게 조합하도록 프롬프트에 명시했습니다. temperature도 1로 올려 표현 다양성을 높였습니다.

**9. 리포트 서식 정리**
- 마크다운 기호(`###`, `***`, `**`) 완전 제거 (AI가 실수로 넣어도 코드에서 한 번 더 걸러냅니다)
- 영역별 결과만 불렛(`-`) 사용, 종합 요약과 코멘트는 줄글
- 레벨 수치(렉사일 숫자, CEFR 등급, 단계 숫자)는 본문에서 제외 — 추천 반 이름만 표시
- 폰트 크기 전반 확대, 헤더와 본문 크기 차등

# 이번 업데이트 (시트 자동저장 + 장바구니 개선)

## 1. 레벨테스트 결과 → 스프레드시트 자동 저장

레벨테스트 리포트가 생성되면, 결과가 자동으로 시트에 한 줄씩 쌓입니다.

**저장되는 열 순서**
```
전화번호 | 제출일시 | 파닉스결과 | 리딩추천반 | 리딩구멍 |
단어추천반 | 단어구멍 | 문법추천반 | 문법구멍 | 발송여부 | 리포트전문
```

- 시험을 안 본 영역은 빈칸으로 남습니다 (B로 진입해 리딩만 봤으면 단어/문법은 공란)
- 파닉스는 게이트 통과 시 공란, 미통과일 때만 "파닉스 기초반부터 시작"이 기록됩니다
- **발송여부**는 코치가 카톡 보낸 뒤 직접 "완료"라고 적는 칸입니다
- 제출일시는 한국 시간 기준입니다

**시트 저장이 실패해도 리포트 생성과 학생 화면은 정상 동작합니다.** 저장 실패는 응답의 `saved: false`로만 표시되고 시험 흐름을 막지 않습니다.

### 필요한 설정

구글 시트에 "쓰기"를 하려면 지금까지 쓰던 "웹에 게시(읽기 전용)"와는 다른 인증이 필요합니다.

| 환경변수 | 값 |
|---|---|
| `GOOGLE_SERVICE_ACCOUNT_KEY` | 서비스 계정 JSON 키 전체 내용 |
| `NEXT_PUBLIC_LEVELTEST_SHEET_LINK` | 레벨테스트 결과 시트 **편집 링크** (여기서 시트 ID를 자동 추출) |

준비 절차:
1. 구글 클라우드 콘솔에서 프로젝트 생성 (조직 없이 만들어야 키 발급이 막히지 않습니다)
2. Google Sheets API 사용 설정
3. 서비스 계정 생성 → JSON 키 발급
4. 결과 시트에 그 서비스 계정 이메일을 **편집자**로 공유
5. JSON 전체를 `GOOGLE_SERVICE_ACCOUNT_KEY`에 등록 후 Redeploy

## 2. 등록 현황판 장바구니 개선

장바구니 안에서 **등록 가능한 것과 대기가 필요한 것을 나눠서** 보여주고, 각각 버튼을 제공합니다.

```
지금 등록 가능 (2개)
  Easy Link 4 (월수금 18:00)
  My Next Grammar 1 (월수금 19:00)
  [2개 수업 등록하기]

대기 신청 필요 (1개)
  Subject Link 7 (화목 19:00) · 대기 3/6명
  [1개 수업 대기 신청하기]
```

- 마감된 수업도 장바구니에 담을 수 있어서, **시간 겹침 검사가 등록·대기 구분 없이 전체를 대상으로** 이뤄집니다
- 시간이 겹치면 두 버튼 모두 감춰지고, 겹치는 과목의 시간표로 바로 이동하는 버튼이 나옵니다
- 등록가능한 수업이 하나라도 있으면 "등록하기" 버튼이 항상 보입니다

## 3. 신청서 사전 채우기 (실제 폼 연결 완료)

등록/대기 버튼을 누르면 구글폼이 열릴 때 **선택한 수업 정보가 미리 입력된 상태**로 열립니다. 학부모는 이름과 연락처만 적으면 됩니다.

**두 폼의 구조가 달라서 각각 다르게 채워집니다.**

등록 신청서 — 요일과 시간이 한 질문
| 필드 | entry ID | 채워지는 값 |
|---|---|---|
| 신청 과목 | entry.264728761 | 리딩 |
| 신청 레벨 | entry.893298491 | Easy Link 4 |
| 희망 요일/시간대 | entry.111945916 | 화목 18:00 |

대기 신청서 — 요일과 시간이 별도 질문
| 필드 | entry ID | 채워지는 값 |
|---|---|---|
| 레벨 | entry.743784151 | Subject Link 7 |
| 수업요일 | entry.1937195432 | 화목 |
| 수업시간 | entry.1294957404 | 19:00 |

**여러 과목을 담았으면 각 칸에 줄바꿈으로 나열됩니다.** 예를 들어 리딩과 문법을 같이 담았다면:

```
[신청 과목]      [신청 레벨]              [희망 요일/시간대]
리딩             Easy Link 4              화목 18:00
문법             My Next Grammar 1        월수금 19:00
```

폼을 여러 번 제출할 필요 없이 한 번에 신청됩니다.

> 폼 질문을 추가하거나 순서를 바꾸면 entry ID가 달라질 수 있습니다. 그럴 땐 폼 편집 화면에서 "미리 채워진 링크 가져오기"로 새 ID를 확인해서 `app/register/page.js`의 `ENROLL_FIELDS` / `WAITLIST_FIELDS` 값을 수정하면 됩니다.

## 4. 한글 줄바꿈 개선 (전체 사이트)

`word-break: keep-all`을 전역으로 적용해서, 한글 어절이 중간에서 잘리지 않습니다. 학생 사이트, 코치 사이트, 등록 현황판, 레벨테스트 모두에 적용됩니다.
